# Dhruv Sonawane — AWS DevOps Portfolio

A responsive, dark-tech portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — main portfolio
- `style.css` — responsive design, animations and graphics
- `script.js` — mobile menu, scroll reveal and dynamic year
- `assets/profile.png` — portfolio hero portrait
- `assets/favicon.svg` — browser icon
- `Dhruv_Sonawane_Resume.pdf` — downloadable resume

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Create a public GitHub repository.
2. Upload all files while preserving the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/root`, then Save.
6. Open the GitHub Pages URL shown by GitHub.

No backend or paid hosting is required.
